FM/DM PLUGIN

A six-voice FM drum machine as a VST3 / AU plugin and a standalone app, for macOS, Windows and Linux. It's free. Paste one line into a terminal to install, and run the same line again to update.

macOS

Open Terminal and paste:

curl -fsSL https://github.com/johnnyhawk02/fm-drum-machine/releases/download/plugin-latest/install.sh | sh
  • VST3 and AU go to ~/Library/Audio/Plug-Ins, and the app goes to ~/Applications.
  • Then restart your DAW, or rescan plug-ins. It's listed as an instrument called fm-dm.
  • It runs on Apple Silicon and Intel Macs, macOS 10.13 or later.

Windows

Open PowerShell (no admin needed) and paste:

irm https://github.com/johnnyhawk02/fm-drum-machine/releases/download/plugin-latest/install.ps1 | iex
  • The VST3 goes to %LOCALAPPDATA%\Programs\Common\VST3. The app goes to %LOCALAPPDATA%\Programs\fm-dm, and it's added to the Start menu.
  • Windows 10 and 11, 64-bit. It uses Microsoft Edge WebView2, which Windows already includes.
  • If your DAW doesn't scan that folder, add it to the DAW's VST3 paths.

Linux

Open a terminal and paste:

curl -fsSL https://github.com/johnnyhawk02/fm-drum-machine/releases/download/plugin-latest/install.sh | sh
  • The VST3 goes to ~/.vst3, and the app goes to ~/.local/bin/fm-dm.
  • It needs WebKitGTK 4.1. On Debian or Ubuntu, install it with: sudo apt install libwebkit2gtk-4.1-0
  • It's 64-bit x86 only, built on Ubuntu 22.04, so most distributions from 2022 on will run it.

Manual download

If you'd rather not use a terminal, download the zip for your system and copy the plug-in into your plug-in folder yourself:

  • fm-dm-mac.zip (VST3, AU, app)
  • fm-dm-windows.zip (VST3, app)
  • fm-dm-linux.zip (VST3, app)

On a Mac, a zip downloaded in a browser is quarantined. If macOS says the plug-in "can't be opened", run xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/fm-dm.vst3 ~/Library/Audio/Plug-Ins/Components/fm-dm.component. The terminal install does this for you.

Using it

  • It follows your DAW's tempo and play/stop, or press play in the plug-in to run it on its own.
  • MIDI notes play the drums: General MIDI drum notes (36 kick, 38 snare, 42/46 hats, 49 cymbal), or C3 upwards for the six drums in order.
  • Presets made in the web version load in the plug-in, and presets made in the plug-in load in the web version.
